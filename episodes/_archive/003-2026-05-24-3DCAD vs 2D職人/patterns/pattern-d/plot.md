# Pattern D: 意外な結末

## Style preset suggestion
ghibli_bg

## Cast
- imaizumi
- sebastian

## 方向性
セバスチャンが3D CADを諦めて2Dに戻ろうとする最終コマで、課長が密かに3D CADを試している意外な結末。ジブリ調の温かみある絵柄で。

## コマ構成（4コマ）

### コマ1
- 場面: 夕暮れの設計室。セバスチャンが3D CADの画面に向かっているが、課長は興味なさそうに2D図面を書いている
- sebastian: 「課長、3次元CADをぜひ……」
- imaizumi: 「いらん。2Dで間に合っとる」
- ト書き: 窓の外は夕焼け。温かいジブリ的背景

### コマ2
- 場面: セバスチャンがため息をついて、3D CADのアプリを閉じようとしている
- sebastian: 「……そうですね、今回は諦めます」
- imaizumi: （背を向けたまま）「まあ、そうしろ」
- ト書き: マウスカーソルが「×」ボタンに近づく

### コマ3
- 場面: セバスチャンが帰り支度をして部屋を出る。課長は一人残って図面を書いている
- sebastian: 「お先に失礼します」
- imaizumi: 「ああ」
- ト書き: ドアが閉まる音

### コマ4
- 場面: 誰もいなくなった設計室。課長が一人でパソコンの前に座り、3次元CADのチュートリアル動画を真剣に見ている
- imaizumi: （独り言）「……操作方法、くらいは知っておくか」
- ト書き: 画面には「3次元CAD 入門編」。課長の横顔は真剣そのもの。窓の外は星空

## 感情曲線
拒絶 → 諦め → 意外な展開 → 温かいオチ（課長の本音）
