# 東北、ぜんぶ回ります — pattern-c (v1 / hybrid)

## Theme
pattern-a + pattern-b のハイブリッド改良版。pattern-a の地図表現 + pattern-b の進路指導室シーンを **「出発」→「現地」のセット感** で繋ぎ、コマ3 で「ぐったり」の強いオチを置き、コマ4 で **電話番号入りの求人募集バナー** に着地する。

### 改善ポイント（ユーザー要望）
1. **コマ1**: 千葉本社の設計室／新事務所をもっと**再現性高く**描く。VPS の `reference-images/会社公式X_サンプルデータ/新事務所/2階事務所/技術部ルーム/` 写真群（IMG_2535〜2541）と PDF p.3-4（機械設計／電気設計 ページ）の特徴を忠実に反映
2. **コマ2**: pattern-b の**進路指導室で先生に説明している**シーンを持ってくる。**コマ1 で広げた東北地図を持って訪問先で広げ直す**ことで、コマ1↔コマ2 の連続性（セット感）を出す
3. **コマ3**: ぐったり度を強める（ネクタイ完全に外す／顔を覆う／駅弁未開封）+ セバスチャンの数字芸オチをしっかり立てる。**新幹線 E5系の車内**を**再現性高く**描く（緑＋ピンクライン、青シート、東北の田園風景）
4. **コマ4**: pattern-a の告知バナー雰囲気を踏襲しつつ、**TEL 043-250-0165 を黒角丸ボックスで大きく**配置（PDF p.8 の見せ方を参考に）
5. **キャラクター**: 追加された I課長 リファレンス IMG_2745.png（短い黒髪、紺色 LINEWORKS 作業着、丁寧で控えめな印象）を踏まえて、若干若めの落ち着いた風貌で統一

**Scene:** 東北のある地方工業高校（**特定校名を出さない**）の**進路指導室の応接スペース**。落ち着いた室内、本棚に各社の採用パンフレットがずらり、壁に「進路指導室」の小さなプレート、窓からは校庭の桜の新緑が少し見える。応接テーブルの中央に **コマ1 と同じ東北地図**（同じ印・同じ折り目）を**広げ直して**、その上にラインワークス採用案内 PDF を並べている。お茶の湯呑みが2客。

**Characters in shot:**

- 先生（**中年男性教諭、後ろ姿 or 横顔**でテーブルを挟んだ向かいに座り、地図を覗き込んで頷いている。地味なジャケット、グレーのスラックス、髪は短く整っている。**具体的な顔は描かない**）
