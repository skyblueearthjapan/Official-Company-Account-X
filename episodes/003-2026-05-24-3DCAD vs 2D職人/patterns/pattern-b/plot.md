# Pattern B: POVシフト

## Style preset suggestion
shinkai_default

## Cast
- imaizumi
- sebastian

## 方向性
セバスチャンが3D CAD画面を見せながら、今泉課長の表情変化（興味→疑問→拒絶→懐かしさ）をカメラが追う。課長の内面にフォーカス。

## コマ構成（4コマ）

### コマ1
- 場面: セバスチャンがタブレットを差し出す。課長のアップ。目が輝いている
- sebastian: 「課長、これが3次元CADの新ツールです」
- imaizumi: （目を細めて興味深そうに見る）「ほう……」
- ト書き: 画面の光が課長の眼鏡に反射

### コマ2
- 場面: 課長が画面を操作しようとする。眉間にしわ
- imaizumi: 「えっ、これ操作がややこしいぞ」
- sebastian: 「慣れればすぐに——」
- ト書き: 指が画面の上で迷子になっている

### コマ3
- 場面: 課長が顔をそむけ、古い2D CADソフトの画面を見る。表情は険しい
- imaizumi: 「やっぱりこっちの方がいい」
- sebastian: 「……」
- ト書き: 2D CADの画面はシンプルで線だけ

### コマ4
- 場面: 課長が古い設計図の束を手に取り、懐かしそうに微笑む。セバスチャンが遠くから見ている
- imaizumi: 「……まあ、悪くはないけど」
- ト書き: 課長の視線は図面に、でも口元は少し緩んでいる。セバスチャン、小さくガッツポーズ

## 感情曲線
興味 → 疑問 → 拒絶 → 懐かしさ＋微妙な肯定（課長視点）
