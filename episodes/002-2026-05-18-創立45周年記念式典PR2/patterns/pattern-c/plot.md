## Panels

### Panel 1 (起) — 受付前、緊張のセットアップ
**Scene:** 新Smart Factory外観の受付前、「披露宴 受付」赤い幟が少し風で傾いている、晴天、青空。地面はアスファルト。
**Characters in shot:** I課長（紺色作業着 + 胸に紅白リボン、傾いた幟を真剣な表情で直す、片手にスマートフォン）、AI Agent 執事 セバスチャン（横で銀のトレイを携え、画面の確認をするポーズ、執事姿）
**Action:** I課長 が幟を真剣に直す。セバスチャンが客の到着情報を伝える。
**Dialogue:**
- セバスチャン: 「お客様、続々お見えでございます」
- I課長: 「（幟を直しながら、汗）よし、間に合った……！」

### Panel 2 (承) — 舞台袖、社長スピーチを見守る
**Scene:** 宴会場の舞台袖、緞帳の影。舞台中央では紺色スーツの田村社長がスピーチ中、背景に樽酒、金屏風、立て看板「旭日単光章受章祝賀会」、観客席は円卓の来賓多数。
**Characters in shot:** I課長（舞台袖から舞台を見つめる、胸に紅白リボン、しみじみとした表情、両手を膝の上で握る）、AI Agent 執事 セバスチャン（横で同じく舞台を見つめる）、舞台上に田村社長（後ろ姿）
**Action:** I課長が感動して舞台を見守る。
**Dialogue:**
- I課長: 「（小声）45年……長かったなぁ……」
- セバスチャン: 「左様でございますね」

### Panel 3 (転) — 鏡開きの瞬間、舞台袖で小さくガッツポーズ
**Scene:** 舞台で鏡開き！樽酒（紅白リボン装飾）が割れる瞬間、紅白の蓋が宙に舞い、米と酒が飛び散る、太鼓が鳴る、観客がワッと盛り上がる、金屏風背景。
**Characters in shot:** I課長（舞台袖でこっそり小さくガッツポーズ、嬉しそうに目をつむる、胸に紅白リボン）、AI Agent 執事 セバスチャン（横で温かく微笑む）
**Action:** I課長が舞台裏で密かに喜びを爆発させる。セバスチャンがそれを見て微笑む。
**Dialogue:**
- I課長: 「（小声、ガッツポーズ）よっしゃ……！」
- セバスチャン: 「（微笑して）お疲れさまでございました」

### Panel 4 (結) — お見送り、感謝の眼差し
**Scene:** 新Smart Factoryの玄関先、夕暮れ近い柔らかな光、来賓数名（後ろ姿）が帰路に立つ、I課長が深いお辞儀でお見送り。
**Characters in shot:** I課長（深いお辞儀、紺色作業着 + 胸の紅白リボン、片手をそっと胸に当てる）、AI Agent 執事 セバスチャン（横で同じく深いお辞儀、銀のトレイ）、来賓数名（後ろ姿）
**Action:** I課長が一人ひとりに深く頭を下げる。
**Dialogue:**
- I課長: 「本当にありがとうございました！」
- セバスチャン: 「またのお越しを心よりお待ち申し上げております」
