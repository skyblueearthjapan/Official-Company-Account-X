# 創立45周年記念式典 PR 第2弾 — pattern-c (v9)

## Theme
**感情の起伏：裏方として奮闘する I課長 視点**。受付準備の緊張 → 司会の開会宣言 → 4人での鏡開き → ホテルロビーで来賓に向かってお見送り。
※ 実際の式典は **50-70代の経営者・取引先・ベテラン社員が参列する重厚な大人の場**。AIで「若い manga キャラ」化しないよう、参列者・スタッフは**全員大人（中年〜高齢）**で描く。
※ Panel 1 の新Smart Factory外観は実写写真の建物形状・看板・幟位置に**忠実に**寄せる。
※ **セバスチャンの銀のトレイには絶対にタブレット・スマホ・PCを乗せない**。シーン文脈に合った接客アイテム（ワイングラス / お猪口 / ウェルカムカード等）を乗せる。

### Panel 1 (起) — 受付前、汗をかきながら幟を整える緊張感のあるシーン — Smart Factory実写忠実
**Scene:** 添付写真 DSCN7286 / DSCN7287 の構図に**忠実に寄せる**：
- 二階建ての**シルバーグレーの波板金属外壁**の現代的な工場建物
- 屋根近くに**横長の窓が2つ並ぶ**（上部）
- 大きな正方形の**ガラス窓**（建物正面 right side、上部）
- 中央やや左寄りに**ガラス扉の入口**、上に小さな庇（canopy）
- 入口の右脇に「**LINE WORKS Smart Factory**」の**赤い縦長看板**
- 入口の脇に「**披露宴 受付**」の**赤い細長い幟旗**（縦書き、白字）が立っているが、**少し風で傾いている**
- 手前に**黒いアスファルト**の駐車場、晴天、青空

**画面構図（重要）— V1 のテイストを再現:**
- 開場直前、慌てて準備中の緊張感ある瞬間
- I課長 が**傾いた「披露宴受付」の幟を両手で掴んで真っ直ぐに立て直している最中**（積極的なアクション）
- 額にうっすら汗、表情は真剣 or 焦り混じり
- セバスチャン は離れた位置で、客の到着情報を I課長 に伝える

**Characters in shot:**
- I課長（紺色作業着 + 胸に紅白リボン胸章、**両手で「披露宴受付」幟のポール（旗竿）を握って傾きを直している**、額にうっすら汗、真剣な表情、汗が一筋流れる）
- AI Agent 執事 セバスチャン（I課長から少し離れた位置で **銀のトレイに白いウェルカムカードのみを載せて**携え、客の到着情報を冷静に伝える、執事姿、solid 描写、胸元にチップ柄ラペルピン）

**Action:** 開場直前、I課長 が**慌てて幟を真っ直ぐに整え直している**。傾きを直す動作（両手で旗竿を掴む）と汗・焦りで「ぎりぎり間に合った」緊張感を表現。セバスチャンは状況を伝える。
**重要制約:**
- 建物の外観、看板の位置を**実写写真DSCN7286/DSCN7287に忠実に**寄せる
- 「披露宴 受付」幟は**少し傾いた状態**で I課長 が**両手で旗竿を握って直している**（自立しているのではなく、I課長 がアクティブに整えている）

- I課長 の表情は**真剣 or 焦り混じり**（にこやかに迎えるポーズではない）
- セバスチャンの**銀のトレイにはタブレット禁止**、白いウェルカムカードのみ

### Panel 4 (結) — ホテルロビーで来賓に向けてお見送り、感謝
**Scene:** **ホテルニューオータニ幕張のロビー or 宴会場玄関先**。高級感のあるホテルインテリア（シャンデリア、絨毯、上品な木目壁、観葉植物）、夕暮れ近い柔らかな光が窓から差す。

**画面構図（重要）:**
- **画面手前 / 中央**に来賓数名（後ろ姿または半側面、**全員50-70代の中年〜高齢の男性**、黒スーツ、帰路に立つ）
- **画面奥**に I課長 と セバスチャン が並んで立ち、**両者ともに来賓側（画面手前）を向いて**深いお辞儀
- I課長 と セバスチャン は**お互いに向き合っていない**。両者の体と顔は**来賓に正対**している
- 視聴者（読者）目線: 来賓の後ろ姿越しに、お見送りする I課長 と セバスチャン の姿が見える

**Characters in shot:**
- I課長（深いお辞儀、紺色作業着 + 胸の紅白リボン、片手をそっと胸に当てる、**顔と体は来賓側を向く**）

**重要制約:**
- 場所は **ホテル内**
- 来賓は**全員大人**、画面手前に位置（後ろ姿）
- I課長 と セバスチャン は**お互いに向き合わない**。両者ともに来賓側（画面手前）を向く
