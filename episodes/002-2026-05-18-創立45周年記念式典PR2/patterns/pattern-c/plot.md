## Panels

### Panel 1 (起) — 受付前、緊張のセットアップ
**Scene:** 新Smart Factory外観の受付前、「披露宴 受付」赤い幟が少し風で傾いている、晴天、青空。地面はアスファルト。背景に建物入口、「LINE WORKS Smart Factory」赤い看板。
**Characters in shot:** I課長（紺色作業着 + 胸に紅白リボン胸章、傾いた幟を真剣な表情で直す、片手にスマートフォン）、AI Agent 執事 セバスチャン（横で銀のトレイを携え、画面の確認をするポーズ、執事姿、solid 描写）
**Action:** I課長 が幟を真剣に直す。セバスチャンが客の到着情報を伝える。
**Dialogue:**
- セバスチャン: 「お客様、続々お見えでございます」
- I課長: 「（幟を直しながら、汗）よし、間に合った……！」

### Panel 2 (承) — 舞台袖、社長スピーチを見守る
**Scene:** ホテルニューオータニ幕張の宴会場、I課長 と セバスチャン は舞台袖（緞帳の影）に立つ。前方には舞台、舞台の正面に立て看板「**株式会社ラインワークス 創立45周年記念式典／田村修二社長 旭日単光章受章祝賀会**」が大きく読める形で設置されている。舞台中央には田村社長がマイクでスピーチ中。背景に金屏風、樽酒、太鼓。観客席は円卓（白いテーブルクロス）に多数の来賓（黒スーツ）、皆**舞台側を向いている**。
**Characters in shot:**
- I課長（舞台袖から舞台側を**正面（舞台）に向いて**見つめる、胸に紅白リボン、しみじみとした表情、両手を膝の上で握る、横顔または斜め前向き）
- AI Agent 執事 セバスチャン（横で同じく舞台を正面に向いて見つめる、solid 物理描写）
- 田村社長 (tamura)（舞台上、マイク持ち、正装、胸に旭日単光章 + 紅白リボン）
**Action:** I課長 と セバスチャン は舞台側を向いて感慨深く見守る（横顔/斜め前向きで会話）。
**重要制約:**
- I課長 と セバスチャン は **正面の舞台に向かって**立つ。来賓と同じ向き（舞台向き）で揃える
- 立て看板は「**株式会社ラインワークス 創立45周年記念式典／田村修二社長 旭日単光章受章祝賀会**」を読める形でフル表示
- 田村社長は実写写真リファレンスを参考に「識別性ありのデフォルメ」で描く
**Dialogue:**
- I課長: 「（小声）45年……長かったなぁ……」
- セバスチャン: 「左様でございますね」

### Panel 3 (転) — 鏡開きの瞬間、舞台袖で小さくガッツポーズ
**Scene:** 舞台で鏡開きの瞬間！田村社長が中央に立ち、樽酒（紅白リボン装飾、「祝」の文字）2つの蓋が割れて紅白の蓋が宙に舞い、米と酒が飛び散る、太鼓が鳴る、観客がワッと盛り上がる、金屏風背景。
**Characters in shot:**
- I課長（舞台袖でこっそり小さくガッツポーズ、嬉しそうに目をつむる、胸に紅白リボン、横顔）
- AI Agent 執事 セバスチャン（横で温かく微笑む）
- 田村社長 (tamura)（舞台上、鏡開きの中心人物、スーツ姿、胸の旭日単光章と紅白リボン）
**Action:** I課長が舞台裏で密かに喜びを爆発させる。セバスチャンがそれを見て微笑む。田村社長は舞台で堂々と。
**重要制約:** 田村社長は**実写写真リファレンスを参考に**識別性ありのデフォルメで描く（顔・髪型・体格を寄せる）
**Dialogue:**
- I課長: 「（小声、ガッツポーズ）よっしゃ……！」
- セバスチャン: 「（微笑して）お疲れさまでございました」

### Panel 4 (結) — ホテルロビーでお見送り、感謝の眼差し
**Scene:** **ホテルニューオータニ幕張のロビー or 宴会場玄関先**。高級感のあるホテルインテリア（シャンデリア、絨毯、上品な木目壁、観葉植物）、夕暮れ近い柔らかな光が窓から差す。来賓数名（後ろ姿、黒スーツ）が帰路に立つ。
**Characters in shot:** I課長（深いお辞儀、紺色作業着 + 胸の紅白リボン、片手をそっと胸に当てる）、AI Agent 執事 セバスチャン（横で同じく深いお辞儀、銀のトレイ、solid 描写）、来賓数名（後ろ姿）
**Action:** I課長 と セバスチャン が一人ひとりに深く頭を下げてお見送り。
**重要制約:**
- 場所は **ホテル内**（Smart Factory ではない）
- 背景はホテルらしい上品なロビー/ホール（シャンデリア・絨毯・木目壁など）
- 来賓のお見送りシーンの感謝感を演出
**Dialogue:**
- I課長: 「本当にありがとうございました！」
- セバスチャン: 「またのお越しを心よりお待ち申し上げております」
