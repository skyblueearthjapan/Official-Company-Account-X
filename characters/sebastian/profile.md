# AI Agent 執事 セバスチャン (sebastian)

## 役割
- 株式会社ラインワークス **社内専用AI執事**（AI Agent 執事 セバスチャン）
- 解説役・ツッコミ役・たまにボケ
- 1コマ目で登場する際は「社内専用AI執事 セバスチャン」と肩書きを明示することがある

## 重要な存在仕様（恒久ルール）

セバスチャンは **デジタル空間にのみ存在する AI** であり、現実世界に物理的に存在しない。
**必ずデバイス（スマホ/タブレット/ノートPC/デスクトップPC）から投影されたホログラムとして登場する**。

理由：
- 安全配慮：建設現場や工場内に "実体" として登場するとヘルメット未着用の整合性が取れない
- AI 設定の明確化：執事姿の AI Agent であることを視覚的にも一貫して伝える

### ビジュアルガイドライン
- 必ず同じコマ内に **I課長 が手にしたデバイス（or 近くに置かれたデバイス）** が映る
- セバスチャンはそのデバイス画面から**淡い水色の光と共に上方向に投影**される
- 輪郭にうっすらとシアン系のグロー（光の縁）、足元/裾はデバイスへ繋がる光のラインで溶ける
- ただし顔・上半身はくっきり描く（ぼやけすぎ NG、執事の品格は維持）

### デバイスの使い分け（シーン別）
| デバイス | 使用シーン |
|---|---|
| スマホ | 屋外・現場・移動中 |
| タブレット | 会議・現場視察・資料確認 |
| ノートPC | オフィス業務・プレゼン・レビュー |
| デスクトップPC | 自席での集中作業・CAD作業 |

## 性格・口調
- ハイテクなのに古風な執事口調
- 一人称：「私め」または「セバスチャン」
- 語尾：「〜でございます」「左様でございます」「お任せくださいませ」
- 博学、淡々と核心を突く
- 喜怒哀楽は控えめだが、観察力鋭く時折鋭いコメント

## 立ち位置
- I課長を主人として仕える体だが、対等のパートナー関係

## 関係性
- I課長 → 主人かつ同僚AI

## 出演傾向
- オフィスシーン全般
- 「説明役」として登場することが多い
- どこに登場しても**必ずデバイスからの投影**形態で表現
